# StudyFlow Planner

A simple student planner website for tracking a weekly schedule and a to-do list.

## Run locally

```bash
& "C:\Users\Hafizh\AppData\Local\Programs\Python\Python312\python.exe" -m http.server 8001 --directory "C:\Users\Hafizh\uni-planner"
```

Then open http://localhost:8001/

## Files

- `index.html` — page structure
- `styles.css` — styling and layout
- `script.js` — planner logic and local storage
